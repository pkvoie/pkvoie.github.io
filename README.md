# PKVoie — données ouvertes

PKVoie est une application professionnelle d'aide au repérage sur les voies ferrées
(point kilométrique en temps réel, repères, caractéristiques de ligne).
Outil d'aide, ne remplace pas les procédures de sécurité en vigueur.

**Ce dépôt public contient uniquement :**

- les **bases de données dérivées** utilisées par PKVoie, publiées sous licence **ODbL**
  comme l'exige cette licence : `pk.js`, `pn.js`, `infos.js`, `reperes.js`, `voie.js`
  (détail et attributions dans [LICENCE-DONNEES.md](LICENCE-DONNEES.md)) ;
- la **version d'essai** de l'application et sa page de téléchargement (`essai/`).

Sources : open data SNCF Réseau (ODbL), carto.graou.info (ODbL),
