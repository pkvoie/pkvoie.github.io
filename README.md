# PKVoie

Aide au repérage sur les voies ferrées : PK en temps réel, recalage sur pancarte, navigation vers un PK, exploration d'une ligne sur photos aériennes IGN (PK qui défilent).

Outil d'aide, ne remplace pas les procédures de sécurité en vigueur.

Données : open data SNCF Réseau (licence ODbL), via carto.graou.info.
Fonds de carte : photographies aériennes et Plan IGN (Géoplateforme), affichés avec Leaflet.
